## 🧩 About the Project

This portfolio was created to present **Nishan Kharel** (and contributions from **Asmita Moktan**) in a clean, high-performance personal website.  
The design follows a **"Monolith Light"** aesthetic — bright, spacious, and focused on content.

Latest major update (April 8, 2026) introduced:
- Dynamic section loading
- Upgrade to Monolith Light design system
- Streamlined user experience

The entire site is static (no backend), making it easy to deploy on **GitHub Pages**, Netlify, or any static hosting.

## 🚀 Getting Started

To run this project locally:

```bash
# 1. Clone the repo
git clone https://github.com/nishankhareln/Nishan_Portfolio.git

# 2. Go into the project folder
cd Nishan_Portfolio

# 3. Open index.html in your browser
open index.html   # or double-click it
```

That’s it – no installation, no dependencies.
